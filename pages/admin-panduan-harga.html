📦 A. Model Harga Dasar

Bentuk paling fundamental bagaimana harga ditentukan untuk produk.

AKTIF
1. Fixed Price
1 produk = 1 harga tetap.
Bolu A = Rp 25.000
AKTIF
2. Price List / Catalog
Paket harga per grup reseller. Fitur F9.1b.
Paket "Promo Cash": Bolu A = Rp 22.000
AKTIF
3. Customer-Specific Price
Harga khusus per reseller. Fitur F9.1.
Bu Yeni: Bolu A = Rp 20.000 (beda dari reseller lain)
RENCANA
4. Tiered by Quantity
Harga turun kalau qty besar.
Beli 1-9 = Rp 25rb; 10-49 = Rp 22rb; 50+ = Rp 18rb
RENCANA
5. Wholesale Price
Harga grosir (bisa via Tiered by Quantity).
Min order 100 pcs = Rp 15.000/pcs
FUTURE
6. Contract Price
Harga kontrak jangka panjang untuk customer tertentu.
Kontrak 6 bulan: Bolu A = Rp 20.000 (berlaku s/d Okt)

💰 B. Diskon

Potongan harga dari harga dasar.

RENCANA F9.7
7. Discount %
Potongan persen.
Total order Rp 500rb, diskon 10% = Rp 450rb
RENCANA F9.7
8. Discount Fixed (Rp)
Potongan nominal tetap.
Total order Rp 500rb, diskon Rp 20rb = Rp 480rb
RENCANA F9.7
9. Tiered Discount by Total
Diskon bertingkat berdasarkan total belanja.
≥500rb = 5%; ≥1jt = 10%; ≥2jt = 15%
RENCANA F9.7
10. Cash Discount
Diskon kalau bayar cash.
Bayar cash = 3% off (atau via order_discount_pct)
FUTURE
11. Early Payment Discount
Diskon kalau bayar cepat.
Bayar <7 hari = -2%
FUTURE
12. Loyalty Tier
Diskon untuk member loyal.
Member Gold = -10%
RENCANA F9.7
13. First Order Discount
Diskon untuk order pertama.
Order pertama = -20%
FUTURE
14. Referral Discount
Diskon kalau bawa teman.
Bawa 1 teman = -Rp 50rb
RENCANA F9.7
15. Seasonal Discount
Diskon musiman (Lebaran, Natal).
Lebaran = -15% (via tgl_mulai/selesai)
RENCANA F9.7
16. Flash Sale
Diskon kilat waktu terbatas.
12:00-14:00 saja = -30%
FUTURE
17. Clearance
Diskon produk mau expired.
Produk exp <3 hari = -50%

RENCANA F9.7

RENCANA F9.7
19. Bundle Pricing
Beli paket = harga khusus.

FUTURE
20. Mix & Match

3 dari kategori "Kue Kering" = Rp 100rb
RENCANA F9.7
21. Gift with Purchase
Beli threshold dapat hadiah.
Beli ≥500rb = gratis 1 kue
FUTURE
22. Sample Bonus
Sample produk baru.
Beli 10 pcs = dapat 1 sample
RENCANA F9.7
23. Free Shipping
Gratis ongkir kalau threshold.
≥Rp 300rb = gratis ongkir

🔗 E. Rule Kombinasi & Prioritas

Bagaimana multiple program digabung atau diprioritaskan.

RENCANA F9.7
28. Stackable
Program bisa digabung.
Promo A + Promo B = apply keduanya
RENCANA F9.7
29. Exclusive
Program tidak bisa digabung.
Pilih A atau B saja
RENCANA F9.7
30. Sequential Calculation
Diskon berurutan.
Diskon 10% dulu, lalu 5% dari hasil
RENCANA F9.7
31. Parallel / Additive
Diskon dihitung dari harga asli, dijumlah.
10% + 5% = 15% dari harga asli
RENCANA F9.7
32. Best-for-Customer
Otomatis pilih kombinasi termurah.
Coba semua kombinasi, kasih yang paling untung customer
FUTURE
33. Best-for-Seller
Otomatis pilih kombinasi paling untung.
Kebalikan dari best-for-customer
RENCANA F9.7
34. Priority Ordering
Priority 1 dihitung dulu.
Program A priority 10, B priority 20
RENCANA F9.7
35. Cap Maximum
Batas maks total diskon.
Max diskon Rp 100rb per order
FUTURE
36. Combinability Matrix
A+B OK, A+C NOT OK.
Promo Cash bisa + Bundle, tapi tidak + Flash Sale
FUTURE
37. Conditional Rules
If-then logic.
IF tier=gold AND total>1jt THEN diskon 15%
RENCANA F9.7
38. Usage Limit
Batas pemakaian.
1x per customer, 100x total
FUTURE
39. Voucher Code
Kode khusus.
Kode "HEMAT10" = diskon 10%

📝 Prioritas Harga di Sistem

Kalau beberapa sumber harga aktif bersamaan, prioritas dari atas ke bawah:

  1. Program aktif — dihitung sebagai diskon (F9.7)
  2. Custom override per reseller — harga khusus (F9.1)
  3. Paket harga — price list (F9.1b)
  4. Harga normal — default PRODUK.SellPrice

Catatan: program punya field basis_harga — bisa set di atas harga final, atau di atas harga normal/paket/custom tertentu.

💡 Contoh Kombinasi Program

Total belanja Rp 1.000.000 dengan 3 program aktif:

  • Program A: diskon 10% (exclusive, priority 1)
  • Program B: diskon Rp 20.000 (stackable, priority 2)
  • Program C: tiered ≥500rb → 5% (stackable, priority 3)

Sequential (berurutan)

Start: Rp 1.000.000
→ A (10%): -Rp 100.000 → Rp 900.000
→ B (Rp 20.000): -Rp 20.000 → Rp 880.000
→ C (5% × 880.000): -Rp 44.000 → Rp 836.000

Parallel (paralel)

A: 10% × 1.000.000 = Rp 100.000
B: Rp 20.000
C: 5% × 1.000.000 = Rp 50.000
Total diskon = Rp 170.000 → Rp 830.000

Best-for-Customer

Kombinasi A only → Rp 900.000
Kombinasi B+C only → Rp 930.000
Kombinasi A+B → Rp 880.000 (A exclusive, C tidak bisa)
