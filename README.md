# Kunang-Kunang 22 - Sistem Pemesanan Reseller

Aplikasi web untuk reseller pesan kue ke kantor.
Reseller buka dari HP, isi pesanan, langsung masuk database kantor.

## Stack
- Frontend : HTML + JS vanilla (GitHub Pages)
- Backend  : Google Apps Script Web App
- Database : Google Sheets
- Notif    : Telegram + fallback WhatsApp (wa.me)
- Export   : SheetJS -> XLSX (kompatibel Jurnal Mekari)

## Struktur Folder
- docs/      : Dokumentasi
- frontend/  : Yang di-push ke GitHub Pages
- backend/   : Kode Apps Script
- scripts/   : Helper PowerShell
- exports/   : File export sementara
