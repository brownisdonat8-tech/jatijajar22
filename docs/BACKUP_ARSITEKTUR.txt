6. KEPUTUSAN DESAIN PENTING
================================================================
- Kunci login       : no_hp (format 62xxx) + PIN (4-6 digit, di-hash SHA-256+salt)
- Kunci produk      : nama_produk HARUS UNIK (ini key di Mekari!)
- Kunci reseller    : DisplayName Mekari = nama_reseller, HARUS UNIK
- OrderNumber format: KK22-{YYYYMMDDHHMM}-{4digit} (contoh: KK22-202610131623-0001)
- CustomerRefNo     : KK22-ORD-{4digit} (ID internal kita)
- Stok              : pakai stok_tersedia & stok_reserved (bukan single "Stock")
- Harga             : disnapshot ke Detail_Pesanan saat pesan
- Pembayaran        : SKIP dulu. Nanti integrasi dengan AR Mekari.
- Role              : owner (read-only), admin (CRUD), reseller (pesanan sendiri)
- Migrasi filter    : Type= customer (reseller), ProductCategory= Barang Jadi
